# Glamora
Private ERP system for salon/spa/parlour management

We will use Stack For the system (Open to suggestions)

- **Frontend**: HTML + CSS + Bootstrap (Admin dashboard and customer-facing interface)
- **Backend**: ASP.NET Core Web API (C#)
- **Database**: Microsoft SQL Server
- **Hosting**: Azure App Services (recommended for ASP.NET), or other Windows-friendly environments
- **Others**: 
  - SignalR (for real-time updates if needed)
  - Twilio / MSG91 for SMS
  - Razor Pages (optional for customer interface)
